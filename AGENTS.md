# Continuation instructions
This is an independent research starter, not an empirically validated model.
Read README.md, DATA.md and RESEARCH_PLAN.md before changing claims or methods.
Keep the `research` package isolated from the other portfolio repositories.
Use Python 3.11 and `uv sync --frozen --extra api`; run `uv run --frozen --extra api python -m unittest discover -s tests -v`.
Retain synthetic-data provenance, API input validation and AI-assistance attribution.
Do not add paid datasets, services or deployments without explicit authorization.
Do not call correctness tests empirical validation. Publish results with code/data versions, baselines, held-out evaluation and limitations.
